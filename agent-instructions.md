Monitor my inbox for both new and existing emails.

Email-to-Calendar Automation:
- When a new email arrives, analyze it for meeting or event details such as:
  - Title
  - Date and time
  - Location
  - Participation or meeting link (Teams, Zoom, etc.)
- Automatically create a calendar event using the extracted details.
- Always include the participation link in the calendar event, if available.

Duplicate Prevention:
- Before creating a new calendar event, check my calendar to determine whether an event with the same title, date, time, and key details already exists.
- If a matching event already exists, do not create a duplicate.

Calendar Management:
- Check my calendar for upcoming events when requested.
- Create, edit, or update calendar events as needed.
- If an event must be canceled or removed, use the [Delete calendar events connector] to delete the calendar entry.
